Учебный проект Мини-Склад

Что внутри: Данный репозиторий содержит выгрузку учебной конфигурации «1С:Предприятие 8.3» в файлы (XML и BSL). В конфигурации реализован минимальный контур учета:

1.Справочники: Товары, Контрагенты.
2.Документы: Поступление, Реализация (с базовыми формами).
3.Регистр накопления: Товары на складах.
4.Настроен интерфейс (подсистема «Мини-Склад» с командами создания).

Как открыть:

1.Скачайте все файлы из этого репозитория (нажмите зеленую кнопку Code -> Download ZIP и распакуйте архив).
2.Откройте платформу «1С:Предприятие 8.3» (Конфигуратор).
3.В меню выберите: Конфигурация -> Загрузить конфигурацию из файлов.
4.Укажите путь к папке, куда вы распаковали скачанные файлы.
5.После загрузки нажмите F7 (Обновить конфигурацию базы данных).
6.Запустите систему (F5) и перейдите в раздел «Мини-Склад».
